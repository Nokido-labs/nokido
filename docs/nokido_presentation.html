05 — Architecture

Four agents.
One goal.

CHEF
Planner
Reads 29 RAG rules, plans the fix strategy, assigns tasks to CLINE.
CLINE
Executor
Clones, patches, tests, commits. Loops with DEBAT until all tests pass.
DEBAT
Validator
Challenges every fix. Hunts edge cases. Never approves broken code.
AUTO
Autonomous Loop
Monitors drift, entropy, heartbeat. Self-heals without human input.
