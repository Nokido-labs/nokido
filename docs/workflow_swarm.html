Swarm

Douze modules, une chaîne à jalons numérotés M0 → M5. Le trait distinctif n'est pas le parallélisme : c'est que chaque worker reçoit un contexte stérile et écrit dans un tableau noir zoné. Un essaim qui partage tout n'est pas un essaim, c'est une seule tête bruyante.

Stérile et zoné

  • build_worker_context construit un contexte fermé ; ScopeViolation sanctionne la sortie de périmètre.
  • sterile_read / assert_writable : lire large, écrire étroit.
  • Le blackboard applique une ACL par ring zone par zone.

Le pré-vol est déterministe

  • M0 validate_swarm_plan juge le plan avant toute dépense de tokens.
  • Déterministe = pas de LLM dans le gatekeeper : un garde qui hallucine ne garde rien.
  • forge_spawn_swarm refuse sans tasks non vide.

Ce qui manque

  • DebateWorker : absent, réclamé 3×.
  • M3 / M4 : jalons jamais déclarés.
  • La délibération collégiale reste parquée depuis le 04/08 — à reprendre par la sélection des rôles.
