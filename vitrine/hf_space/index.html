Nokido

A local-first runtime for an artificial organism: the nervous system and physiology that let local models, cloud providers and coding agents work together on your machine, without becoming a heap of independent agents.

Source on GitHub nokido-agent on PyPI What it does not claim

Follow a request

Illustration of the documented path. Not a recorded run.

Call

A coding agent calls a tool on the hub through MCP. It does not touch files or the shell directly.

Gate

The hub checks the action before it runs: role, AST validity, secret scanning, egress rules.

Route

Work that needs a model goes to a local model or, by use case, to a cloud provider, with a local fallback.

Protect

What leaves for the cloud passes the semantic firewall; what comes back is checked on the way in.

Remember

Results and decisions are anchored in memory with their provenance, retrievable later.

Regulate

If CPU, RAM or queues come under pressure, hormone-like signals and homeostasis slow down or shed work.

The self-improvement loop

How a change to Nokido itself is meant to travel, and where it stands today.

Observe

The body records what went wrong or could be better.

Hypothesis

A candidate change is proposed for one well-defined setting.

Isolated trial

The change is tried apart from the running organism.

Judge

Regression tests decide; a capability regression brakes the loop automatically.

Decide

One gate: the owner must arm evolution, a brake can halt it, a human lock can hold it.

Watch and revert

After a change, the body keeps measuring and must be able to prove a revert.

Status: guarded. The judge and the brakes exist; arming is an owner decision. As of 2026-10-13, no mutation has been applied autonomously.

Declared, observed, verified

DeclaredWhat the code or a config says. An organ can exist in code without being wired.
ObservedWhat a probe sees right now. A port that answers does not prove a model is loaded.
VerifiedWhat a test or an artifact proves. A probe that cannot look reports ILLISIBLE, never “no”.

What Nokido does not claim

  • AGI
  • guaranteed self-healing
  • perfect autonomy
  • perfect self-awareness
  • universal protocol compatibility
  • production-grade stability for every subsystem
  • production neuromorphic hardware support

Nokido is an alpha-stage research and engineering project. The repository, its tests and its live capability checks are the authoritative source for the current state.
