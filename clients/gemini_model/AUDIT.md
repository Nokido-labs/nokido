# Audit des lecteurs de GEMINI_MODEL dans Nokido

Date : 2026-10-15  
Décision owner : Le modèle Gemini doit dépendre de l'**APPELANT**, jamais d'un `GEMINI_MODEL` global figé.  
Contexte de quota et facturation :
- **Voie OAuth / abonnement** (Gemini CLI / Antigravity) : Payée par l'owner (accès aux modèles puissants `gemini-2.5-pro`, `gemini-3.1-pro-preview`).
- **Voie clé API** (`GEMINI_API_KEY`) : Palier **GRATUIT**, quotas stricts comptabilisés par modèle. Mesure du 18/08 : la famille `pro` renvoie 429 (quota dépassé), la famille `flash` renvoie du texte vide, **seule la famille `flash-lite` répond**.
- Aujourd'hui, `GEMINI_MODEL` vaut `gemini-flash-lite-latest` au coffre et `gemini-2.5-pro` dans `Nokido.env`. Un lecteur qui lit aveuglément cette variable globale échoue sur la voie clé API si elle pointe sur pro ou flash.
