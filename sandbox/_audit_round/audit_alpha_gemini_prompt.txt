## STATE MACHINE DES STATUTS biblio_raw

Statuts : unverified -> queued -> searching -> reviewed -> promoted | rejected

### Transitions explicites

| De                | Vers       | Declencheur                                              |
|-------------------|------------|----------------------------------------------------------|
| (creation)        | unverified | INSERT initial par extracteur (alpha2)                   |
| unverified        | queued     | Sanitization PASSED (URL whitelist OK + DOI valid)       |
| unverified        | rejected   | Sanitization FAILED                                      |
| queued            | searching  | Daemon worker pick up (alpha3)                           |
| searching         | reviewed   | SearXNG repond, results_json sauve                       |
| searching         | rejected   | SearXNG retourne 0 result OR engine error all-down       |
| reviewed          | promoted   | TUI `@biblio promote <id>` par utilisateur               |
| reviewed          | rejected   | TUI `@biblio reject <id> <reason>`                       |
| promoted          | (final)    | INSERT bibliography + INSERT rag_chunks                  |

```
while not stop_signal:
    entry = SELECT * FROM biblio_raw WHERE status="queued" LIMIT 1
    if not entry: sleep 5; continue
    UPDATE status="searching"

    results = searxng_search(query, engines="arxiv,crossref,openalex")

```
