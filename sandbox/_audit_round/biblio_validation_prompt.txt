## 6. Configuration recommandee pour le worker biblio

### Strategie multi-passes par source

Pour chaque entree biblio a chercher, 3 passes :

**Pass 1 - DOI resolution (si manquant)** :
- engines: `crossref,arxiv,openalex`
- query: `"<title>" <author> <year>`
- objectif: trouver le DOI canonique

**Pass 2 - PDF / acces complet** :
- engines: `arxiv,openairepublications,openlibrary` + plugin `Open_Access_DOI_rewrite`
- query: `<title> <author> filetype:pdf` ou via DOI direct
- objectif: pdf_url + version ouverte

**Pass 3 - Critique / commentaires / implementations** :
- engines: `google scholar,semantic scholar,duckduckgo`
- query: `<title> review OR critique OR implementation`
- objectif: contexte, popularity, refs croisees
- multi-langue : aussi `language=fr` pour francophone

### Espacement des requetes

```
worker_loop:
  for entry in queue:
    for pass_num in [1, 2, 3]:
      results = searxng_search(...)
      sleep(3.0)  # politesse de base
      if 'semantic scholar' in unresponsive:
        skip semantic scholar pendant 60s
```

## 7. Anti-pollution / sanitization a la reception

Avant insert dans `biblio_raw` :

1. **Validation DOI** : regex `^10\.\d{4,9}/[-._;()/:A-Z0-9]+$` (case insensitive)
2. **Validation arxiv ID** : regex `^\d{4}\.\d{4,5}(v\d+)?$`
3. **Validation ISBN** : 10 ou 13 chiffres, checksum verif
4. **URL whitelist** : domaines acceptes pour `pdf_url`/`url` :
   - arxiv.org, doi.org, oadoi.org, openalex.org
   - openlibrary.org, semanticscholar.org, scholar.google.com
   - openreview.net, neurips.cc, aclanthology.org, ijcai.org
   - acm.org, ieee.org, springer.com, sciencedirect.com
   - github.com (papiers avec code)
   - nokido.internal (interne)
   - tout `*.edu` et `*.gov` (educatif/gouv)
5. **Sanitize content snippet** : regex Q5 deja definies
   - bloquer override patterns (`ignore previous`, `you are now`, etc.)
   - encadrement code/example whitelisted
6. **Title duplication check** : fuzzy match (Levenshtein < 5%) avant insert
